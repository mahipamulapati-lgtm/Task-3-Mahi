ATM Interface

Description:
The ATM Interface is a Java console application that simulates the basic functionalities of an Automated Teller Machine (ATM). 
Users can perform banking operations such as checking account balance, depositing money, and withdrawing money.
The project demonstrates Object-Oriented Programming (OOP) concepts including classes, objects, encapsulation, methods, and input validation.

Features:
Check Account Balance
Deposit Money
Withdraw Money
Input Validation
Transaction Messages
Menu-Driven Interface

Technologies Used:
Java
Object-Oriented Programming (OOP)
Scanner Class
Classes and Objects
Encapsulation

Project Structure:
ATM Class
BankAccount Class
Main Class

How to Run:
Open Terminal/Command Prompt.

Compile the program:
javac AtmInterface.java

Run the program:
java AtmInterface

Sample Operations:
Check Balance
Deposit Money
Withdraw Money
Exit
